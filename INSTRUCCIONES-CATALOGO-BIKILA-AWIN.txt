ACTUALIZAR BIKILA EN EL FUTURO
1. Sustituir data/sources/awin/bikila-es.csv.gz por el feed nuevo.
2. Ejecutar:
   npm run awin:bikila:dry
3. Revisar data/catalog/import-reports/bikila-es-last.json.
4. Ejecutar:
   npm run awin:bikila:import
   npm run quality

IMPORTAR OTRO ANUNCIANTE AWIN
1. Añadir el merchant aprobado a data/catalog/merchants.json.
2. Añadir su perfil a data/catalog/awin-import-profiles.json si necesita reglas propias.
3. Ejecutar:
   node scripts/import-awin.mjs RUTA_DEL_FEED --merchant ID_DEL_MERCHANT --dry-run
4. Si el informe es correcto, repetir sin --dry-run y ejecutar npm run quality.
