Microsoft SharePoint Server 2019 Standard Device CAL (Licencia de Acceso de Cliente) es un modelo de licencia ofrecido por Microsoft para acceder y utilizar SharePoint Server 2019 Standard. Una Device CAL es un tipo de licencia que se asigna a un dispositivo específico (como una computadora o una tableta) en lugar de a un usuario individual. Con una Device CAL, cualquier usuario que acceda a SharePoint Server 2019 Standard desde ese dispositivo con licencia puede utilizar sus funciones y características. NO SE NECESITA CLAVE DE PRODUCTO, se envía un ID de la licencia y Número de autorización asociado a su empresa.
