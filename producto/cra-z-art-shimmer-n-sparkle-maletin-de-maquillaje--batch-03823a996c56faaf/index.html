¡Deja volar tu imaginación con Shimmer ’n Sparkle! ¿En qué consiste? Con el maletín de maquillaje Shimmer 'n Sparkle estarás siempre lista para maquillarte y maquillar a todas tus amigas. Un set de maquillaje repleto de sombras y brillos de labios para que cada día te maquilles diferente. ¿Qué incluye? Incluye sombras de ojos, coloretes, brillos de labios, pintalabios, brochas y pinceles. ¿Qué aprenden? Es un juguete simbólico que reproduce la imitación de roles adultos e incentiva que las niñas imiten a sus mamás. Este juguete desarrolla la habilidad manual, el aprendizaje y fomenta la imaginación y la socialización. ¿Qué debes saber? El maletín cerrado mide 25, 5 x 5 x27, 5 cm y está fabricado de cartón. Incluye 1 espejo para mirarse mientras se maquillan. Se recomienda para niños a partir de 8 años. Set de maquillaje gluten free.
