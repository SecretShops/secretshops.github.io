Microsoft SharePoint Server 2016 Standard User CAL es un tipo de licencia que permite a un usuario acceder y utilizar las funciones y características de SharePoint Server 2016 Standard. Es necesario adquirir una CAL de usuario por cada usuario individual que interactúe con el servidor SharePoint. La CAL de usuario proporciona derechos de acceso a diversas capacidades de SharePoint Server 2016 Standard, como la colaboración en documentos, la gestión de contenido, la creación de sitios web, la integración con Microsoft Office, la sincronización de documentos y otras funciones empresariales. NO SE NECESITA CLAVE DE PRODUCTO, se envía un ID de la licencia y Número de autorización asociado a su empresa.
