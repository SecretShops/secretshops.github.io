SUBIDA MANUAL A GITHUB
1. Descomprime este ZIP.
2. Copia TODO su contenido dentro de la carpeta local del repositorio.
3. Cuando Windows pregunte, selecciona reemplazar los archivos existentes.
4. Comprueba en GitHub Desktop que no aparece ningún conflicto.
5. Escribe un resumen como:
   Añadir catálogo SHOKZ ES con enlaces Impact
6. Pulsa Commit to main.
7. Pulsa Push origin.
8. Espera a que GitHub Pages termine de desplegar.
