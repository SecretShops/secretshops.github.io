SECRETShop — PARCHE SEO SIN ARCHIVOS GENERADOS

Este paquete evita conflictos con los catálogos y fichas que actualiza la API de Impact.

ORDEN:
1. En GitHub Desktop, pulsa "Abort merge".
2. Actualiza main con "Fetch origin" / "Pull origin".
3. Copia sobre el repositorio únicamente el contenido de esta carpeta.
4. Confirma que solo cambian estos archivos:
   - index.html
   - package.json
   - scripts/build-regional-site.mjs
   - scripts/validate-seo.mjs
   - tests/seo-contract.test.mjs
   - docs/SEO-SEARCH-CONSOLE.md
   - data/config/seo-state.json
5. Haz commit y push.
6. Ejecuta Actions > Actualizar catálogo Shokz desde Impact V4 > Run workflow,
   marcando force=true, para reconstruir y validar todas las fichas y sitemaps.

NO COPIAR NI RESOLVER MANUALMENTE:
- data/catalog/**
- producto/**
- sitemap*.xml
- data/config/regions-build-report.json
Esos archivos se regeneran automáticamente con los datos actuales.
